# 90. 用語集

プロジェクト内で使う言葉の意味をそろえるための一覧です。  
かるた用語も、アプリ用語もここに足していきます。

迷ったら「この用語集の意味」を優先します（一般的な意味と違う場合は、その旨を書いておく）。

---

## 使い方

- 新しい言葉が出たらすぐ追記する
- 「このプロジェクトでの意味」を短く書く
- 紛らわしい言葉は「似ている言葉との違い」も書く

## 優先度の言葉

| 用語 | 意味 |
|------|------|
| 必須 | 最初の版にないと困る |
| あると嬉しい | あると良くなるが、後回しでも進める |
| 今回はやらない | 意図的にスコープ外にする |
