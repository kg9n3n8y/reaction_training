このフォルダは、アプリを作る前に「何が欲しいか」「何を作るか」を整理するための場所です。  
実装コードはまだ書かず、まずはここに考えを書き出していきます。

## 進め方の目安

1. **1ファイルずつ**埋める（一気に全部埋めなくてOK）
2. 迷ったら `[未記入]` のまま残し、[05_未決事項.md](./05_未決事項.md) にメモする
3. 「必須 / あると嬉しい / 今回はやらない」を早めに区別する
4. ある程度固まったら、要件をもとに実装の相談に進む

---

## 言葉の使い分け（このプロジェクト内の約束）

| 言葉 | 意味 | 例 |
|------|------|----|
| **要求** | 利用者目線の「こうしたい」「こうなりたい」 | 出札を聞いて素早く反応する練習がしたい |
| **要件** | 要求を満たすためにアプリが持つべき具体条件 | 音声再生後◯秒以内の反応を記録できる |

難しい言葉は [90_用語集.md](./90_用語集.md) にも追記していく。

## ひな形の使い方

- `[未記入]` … まだ書いていないところ。ここを埋めていく
- `<!-- メモ: ... -->` … 書くときのヒント（完成後に消してOK）
- 表の空行はコピーして増やしてOK
