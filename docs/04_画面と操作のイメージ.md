## 2. 画面遷移（ざっくり流れ）


## 4. 操作シナリオ（具体的な1体験）

### シナリオA: 初めて使う人が1セット終わるまで

1. アプリを開く → 初回設定画面へ
2. 4枚前後の札（画像）を選び、問数を選んで「練習を始める」
3. 出札の音が流れ、表示された札画像から正解をタップ → 正誤と ms を確認（繰り返し）
4. 1セット終了 → 平均 ms を結果画面で確認

**つまずきそうなポイント:**

- ブラウザの音声自動再生制限（初回はユーザー操作後に再生が必要かも）
- 札の選び方がわからない

### シナリオB: 2回目以降の「すぐ練習したい」流れ

1. アプリを開く → ホームの「すぐ開始」をタップ
2. 練習中 → 音を聞いて札をタップ
3. 結果確認 → 「もう一回」またはホームへ

## 5. 入力方法の方針

| 項目 | 記入欄 |
|------|--------|
| 反応の入力方法 | タッチスクリーンで札画像をタップ（正解の1枚を選ぶ） |
| 誤操作への配慮 | 札ボタンは指で押しやすい大きさ。不正解タップは即終了（やり直しなし） |
| 音の扱い | リポジトリ同梱音声を再生。計測は再生開始からタップまで |
| 中断・再開 | [未記入] |
| 問題間の間隔 | 各問のフィードバック後、1〜2秒待ってから次問へ自動遷移 |
