## 4. 操作シナリオ（具体的な1体験）

### シナリオA: 初めて使う人が1セット終わるまで

1. アプリを開く → 初回設定画面へ
2. 4枚前後の札を選び「練習を始める」
3. 出札の音が流れ、表示された札から正解をタップ（繰り返し）
4. 1セット終了 → 各問の反応時間（ms）を結果画面で確認

**つまずきそうなポイント:**

- ブラウザの音声自動再生制限（初回はユーザー操作後に再生が必要かも）
- 札の選び方がわからない

### シナリオB: 2回目以降の「すぐ練習したい」流れ

1. アプリを開く → ホームの「すぐ開始」をタップ
2. 練習中 → 音を聞いて札をタップ
3. 結果確認 → 「もう一回」またはホームへ
