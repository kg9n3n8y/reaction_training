## よく出る検討テーマ（埋まっていなければ追加してOK）

### 練習の中身について

- [x] 何をもって「正解の反応」とするか → 表示札のうち正解の1枚をタップ
- [x] 1セットの回数 → 10 / 20 / 30 問から選択
- [x] 出題のランダム / 決まった順 → ランダム
- [ ] 競技ルールにどこまで寄せるか → [未記入]

### 音・札・著作権について

- [x] 音源は誰が用意するか → 開発者がリポジトリに同梱
- [x] 札面画像は必要か → 必要（用意済み・後で配置）
- [ ] 公開するときの権利・クレジット → [未記入]

### 利用環境について

- [x] スマホ専用でよいか、PCも必要か → スマホ・タブレット優先（PCは当面想定外）
- [ ] オフライン対応は必要か → [未記入]
- [x] 複数人で結果を比べたいか → 今回はやらない

### データについて

- [x] 履歴をサーバーに残すか、端末だけか → サーバー保存なし（GitHub Pages 完結）
- [x] ログインは必要か → 不要
