ここでは実装の詳細よりも、「何ができたら嬉しいか」を優先して書いてOKです。

## 優先度の意味

| 記号 | 意味 |
|------|------|
| **必須** | これがないと最初の版として意味が薄い |
| **あると嬉しい** | あると練習が良くなるが、後回しでもOK |
| **今回はやらない** | 今回のスコープ外。忘れるためではなく、意図的に外す |
