## 2. カテゴリ別の洗い出しメモ

<!-- メモ: 上の表に入れる前のラフ用。カテゴリは自由に増やしてOK -->

### 練習の開始・進行

- 初回のみ設定 → 2回目以降はワンタップ開始
- 隙間時間にサッと1セット終わらせたい

### 札・音・出題のしかた

- 対象札は4枚前後（最大8枚）
- 音源はリポジトリ同梱
- 1セットの問数は設定で選択（具体の選択肢は要確認）
- 出題順（ランダム / 固定）は [未記入]

### 反応・入力のしかた（タップ / キー / その他）

- 複数表示された札から正しい札をタップ
- 誤タップ時の扱い（お手つき相当）は [未記入]
- 計測は音声再生開始からタップまで（正解・不正解問わず）

### 結果の見え方（タイム・正誤・履歴）

- 練習中: 各問のあとに正誤（○/×）と反応時間（ms）
- 結果画面: 平均 ms を表示
- 履歴の長期保存は [未記入]（MVP外候補）

### 設定・カスタム（難易度・回数・音量など）

- 札の枚数・対象札の選択・1セットの問数（初回設定）
- 音量などは [未記入]

### 学習・振り返り（傾向分析、苦手札など）

- 当面はやらない想定（今回はやらない候補）

### その他（ログイン、共有、オフラインなど）

- ログイン不要、GitHub Pages 完結
- 設定の端末内保存（localStorage 等を想定）

## 3. MVP（最初の小さく使える版）に入れる要求

<!-- メモ: 「必須」の中から、最初の1週間〜数週間で触れそうな最小セット -->

**MVPに入れる要求ID:**

- R-01, R-02, R-03, R-04, R-05, R-06, R-07, R-08, R-09

**MVPの一文説明:**

> 初回に札（4〜8枚）と問数を設定し、札画像を見ながら出札音に反応して正解をタップ。各問で正誤と ms がわかり、セット後は平均 ms が表示される。2回目以降はワンタップで開始。

**MVPに入れない（あと回し）:**

- 履歴の長期保存・グラフ化
- 苦手札分析
- ログイン・オンライン対戦

## 4. 受け入れの目安（要求が満たされたかのチェック）

<!-- メモ: 「動いた」ではなく「練習として使える」観点で書くと良い -->

| 要求ID | こう動けばOK | まだ足りないと感じる条件 |
|--------|--------------|--------------------------|
| R-01 | 音再生後、表示された札のうち正解をタップできる | 札が表示されない、音が鳴らない |
| R-02 | 4〜8枚の範囲で練習対象を選べる | 枚数を変えられない |
| R-03 | 各問タップ後に ms が表示され、結果画面に平均 ms がある | 表示がない、または秒のみ |
| R-06 | 設定画面で1セットの問数を選べる | 問数が固定で変更できない |
| R-07 | 各問のあとに正誤と ms が表示される | フィードバックがない |
| R-08 | セット終了後に平均 ms が見える | 1問ごとの一覧しかない |
| R-09 | 札画像が練習画面に表示される | 画像が読み込めない・表示されない |
| R-04 | 2回目以降、ホームから1タップで前回設定の練習が始まる | 毎回設定し直しが必要 |
| R-05 | 同梱音声が問題なく再生される | 音源が読み込めない・途切れる |
